# Portfolio

Personal portfolio of Aditya Narayan Datta Mallick, built with [Next.js](https://nextjs.org).

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Editing content

All content (experience, research, projects, skills, education, contact links) lives in
[`data/profile.ts`](data/profile.ts). Layout and styling are in `app/` and `components/`.
